# ربات تلگرام نصب خودکار WhiteDNS Soar Server

این ربات روی سرور لینوکس شما اجرا می‌شود و پنل WhiteDNS را روی سرورهای مقصد نصب، تعمیر و حذف می‌کند. رکوردهای DNS کلودفلر را هم می‌سازد.

## روند نصب پنل

1. ربات به سرور مقصد وصل می‌شود و آن را **فقط می‌خواند**: سیستم‌عامل، پورت‌ها و نصب قبلی.
2. رکوردهای کلودفلر را بررسی می‌کند و نامی را که سرویس دیگری دارد بازنویسی نمی‌کند.
3. خلاصهٔ تغییرات را نشان می‌دهد و تا تأیید شما چیزی تغییر نمی‌کند.
4. رکوردها را ثبت می‌کند و عامل نصب را **جدا از SSH** روی سرور اجرا می‌کند. قطع ارتباط یا ریستارت ربات نصب را متوقف نمی‌کند.
5. نصب مثل نصاب رسمی تراکنشی است. اگر سرویس‌ها سالم بالا نیایند، سرور به حالت قبل برمی‌گردد.
6. HTTPS با قابلیت داخلی پنل فعال می‌شود. nginx و certbot لازم نیستند.
7. تانل با ابزار رسمی `soar-check` واقعاً آزمایش می‌شود و نتیجه، حتی اگر ناموفق باشد، به شما گزارش می‌شود.

نصب دوباره با همان تانل، حساب‌ها، کلیدها و آدرس خصوصی را حفظ می‌کند. رمز ادمین فقط با تأیید شما عوض می‌شود.

## پیش‌نیاز سرور مقصد

- Ubuntu 22/24/26 یا Debian 12/13، با معماری amd64 یا arm64، و systemd
- یک IPv4 عمومی
- پورت‌های UDP و TCP شماره ۵۳، و TCP شماره ۸۰ و ۴۴۳ در فایروال پرووایدر
- ورود با root، یا کاربری با `sudo` که به tty نیاز ندارد
- دامنه‌ای که نام تانل آن از ۲۴ کاراکتر بیشتر نشود (حد پنل). ربات در صورت نیاز برچسب کوتاه‌تری انتخاب می‌کند.

## نصب ربات

ربات به Node.js 22.13 به بالا نیاز دارد و `deploy.sh` آن را نصب می‌کند.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DarkPoesidon/whitedns-panel-installer-bot/main/deploy.sh)
```

با توکن:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DarkPoesidon/whitedns-panel-installer-bot/main/deploy.sh) YOUR_BOT_TOKEN
```

## به‌روزرسانی

```bash
bash /opt/whitedns-bot/update.sh
```

یا `/update` در تلگرام. این دستور فقط برای شناسه‌های `ADMIN_CHAT_IDS` در `/opt/whitedns-bot/.env` کار می‌کند و شناسهٔ شما را `/id` نشان می‌دهد. اگر نسخهٔ جدید بالا نیاید، به commit قبلی برمی‌گردد.

## حذف ربات

```bash
bash /opt/whitedns-bot/uninstall.sh
```

این دستور فقط ربات را حذف می‌کند و پنل‌های نصب‌شده روی سرورهای دیگر دست نمی‌خورند.

## دستورات تلگرام

| دستور | کار |
|---|---|
| `/start` | نصب پنل جدید |
| `/status` | فهرست پنل‌ها و آدرس‌ها |
| `/repair` | تعمیر: تکمیل نصب ناقص، راه‌اندازی سرویس‌ها، تلاش دوباره برای HTTPS، آزمایش تانل، رمز ادمین تازه |
| `/dns` | مشاهده، افزودن، ویرایش و حذف رکوردهای کلودفلر |
| `/uninstall` | حذف پنل از سرور، با نگه داشتن یا پاک کردن دیتابیس |
| `/update` | به‌روزرسانی ربات (فقط مدیر) |
| `/id` | نمایش شناسهٔ چت |
| `/reset` | لغو عملیات جاری و پاک کردن اطلاعات موقت |

در ترمینال سرور ربات، `whitedns-bot` یا `bot` منوی مدیریت را باز می‌کند.

## امنیت

- رمز SSH، کلید SSH و توکن کلودفلر فقط در حافظه می‌مانند (حداکثر ۳۰ دقیقه) و روی دیسک ربات ذخیره نمی‌شوند.
- به‌روزرسانی از نسخه‌های قبل، اسرار ذخیره‌شدهٔ قدیمی را از دیتابیس پاک می‌کند. **اگر نسخهٔ قدیمی را اجرا کرده‌اید، رمزها و توکن‌هایی را که به آن داده‌اید عوض کنید.**
- رمزها هرگز در خط فرمان ارسال نمی‌شوند.
- کلید میزبان SSH در اولین اتصال ثبت می‌شود و تغییر آن عملیات را متوقف می‌کند.
- ربات با کاربر محدود `whitedns-bot` اجرا می‌شود و فقط در چت خصوصی کار می‌کند.

## تنظیمات `.env`

| متغیر | کار |
|---|---|
| `BOT_TOKEN` | توکن از BotFather |
| `ADMIN_CHAT_IDS` | شناسه‌های مجاز برای `/update`، جدا با کاما |
| `SOAR_PANEL_VERSION` | نسخهٔ پنل. پیش‌فرض نسخهٔ آزموده و قفل‌شده با هش است |
| `TELEGRAM_API_ROOT` | برای سرورهایی که دسترسی به تلگرام ندارند: آدرس Bot API خصوصی |
